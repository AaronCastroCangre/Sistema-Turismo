
# 🌍 Sistema Turismo

Aplicación móvil desarrollada con **SwiftUI** y **Firebase** para descubrir, crear y administrar destinos turísticos. Los visitantes pueden explorar destinos en modo invitado, mientras que los usuarios registrados pueden crear destinos, subir imágenes, comentar publicaciones y gestionar su perfil. La aplicación integra mapas interactivos, consulta del clima mediante una API y una interfaz moderna basada en la arquitectura **MVVM**.

---

## ✨ Funcionalidades

- 🔐 Registro, inicio y cierre de sesión mediante Firebase Authentication.
- 👥 Modo invitado con acceso limitado.
- 👤 Gestión del perfil de usuario.
- 📍 Creación, edición y administración de destinos turísticos.
- 💬 Sistema de comentarios en los destinos.
- 🖼️ Subida y visualización de imágenes.
- 🔍 Vista de imágenes en pantalla completa con zoom.
- 🗺️ Mapas interactivos con MapKit.
- 🌤️ Consulta del clima mediante una API.
- 🎨 Soporte para tema claro y oscuro.
- 📱 Interfaz moderna desarrollada completamente con SwiftUI.

---

## 🏗️ Arquitectura

El proyecto sigue el patrón **MVVM (Model–View–ViewModel)** para separar la lógica de negocio de la interfaz de usuario, facilitando el mantenimiento, la escalabilidad y la organización del código.

## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/TU_USUARIO/Sistema-Turismo.git
```

### 2. Abrir el proyecto

Abre el archivo `.xcodeproj` o `.xcworkspace` con **Xcode**.

### 3. Configurar Firebase

Agrega tu archivo:

```
GoogleService-Info.plist
```

> **Nota:** Este archivo no se incluye en el repositorio por motivos de seguridad. Debes crear un proyecto en Firebase y descargar tu propio archivo de configuración.

### 4. Ejecutar

Selecciona un simulador o un dispositivo físico y presiona:

```
⌘ + R
```
